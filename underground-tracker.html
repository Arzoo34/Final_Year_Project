⛏ SafeMine — Hardware Integration Guide

Step-by-step: Connect your Dhanalakshimi ESP32 Smart Helmet to the SafeMine Dashboard

📡
How It All Works
Full data flow from hardware to dashboard
ESP32 Smart Helmet  (Dhanalakshimi hardware)
  |
  |  WiFi  ---  HTTP POST JSON  --->
  |
  v
YOUR PC  :  POST http://YOUR_PC_IP:3001/api/telemetry
  |
  |  handleHelmetUpdate()  (already coded in server.js)
  |
  v
SQLite DB  +  WebSocket broadcast
  |
  v
SafeMine Dashboard  http://localhost:3001  [LIVE DATA]
✓ The backend is already updated! POST /api/telemetry is live in your server.js — you only need to configure the ESP32 side.
1
Find Your PC's IP Address
The ESP32 sends data to this IP address

Your ESP32 and PC must be on the same WiFi network. Then find your PC IP:

  1. Press Windows Key + R, type cmd, press Enter
  2. In the black window type:
ipconfig
  1. Find "Wireless LAN adapter Wi-Fi" section
  2. Look for IPv4 Address — it looks like: 192.168.1.105
Example output:

Wireless LAN adapter Wi-Fi:
  IPv4 Address . . . : 192.168.1.105
  Default Gateway . : 192.168.1.1
⚠ Write this IP down — you need it in Step 3. It may be 192.168.0.X or 10.0.0.X on your network.
2
Clone & Open the Hardware Code
Get the dhanalakshimi firmware into Arduino IDE

If you haven't cloned the repo yet:

  1. Open Command Prompt
  2. Run:
git clone https://github.com/Deepak-Moorthi/dhanalakshimi.git
  1. Open Arduino IDE
  2. Click File → Open
  3. Navigate to the cloned folder and open the .ino file
If you already have the folder, just open Arduino IDE and open the .ino file directly.
3
Change 3 Lines in the Firmware
Set your WiFi credentials and your PC's IP

In the firmware .ino file, find and change these lines:

🔴 BEFORE (what it says now):

const char *WIFI_SSID       = "your_wifi_name";
const char *WIFI_PASS       = "your_wifi_password";
const char *CLOUD_SERVER_URL = "http://your-dashboard-api.com/api/telemetry";

🟢 AFTER (what to change it to):

const char *WIFI_SSID       = "YOUR_ACTUAL_WIFI_NAME";       // your WiFi name
const char *WIFI_PASS       = "YOUR_ACTUAL_WIFI_PASSWORD";   // your WiFi password
const char *CLOUD_SERVER_URL = "http://192.168.1.105:3001/api/telemetry"; // PC IP from Step 1
⚠ Replace 192.168.1.105 with YOUR actual IP from Step 1. Keep :3001/api/telemetry exactly as shown.

Also set the Helmet ID (one per helmet):

const char *DEVICE_ID   = "DHANA-001";      // change to DHANA-002 for second helmet
const char *WORKER_NAME = "Ravi Kumar";     // actual worker name
const char *ZONE        = "Zone A";         // Zone A / B / C etc.
4
Make Sure Your Firmware Sends HTTP POST
Check or add the HTTP sending code

Your firmware must POST a JSON body to /api/telemetry. Check if your firmware already has HTTPClient code. If not, add this:

Add at the top of your .ino file (if not already there):

#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

Add this function to your .ino file:

void sendToSafeMine() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  http.begin(CLOUD_SERVER_URL);
  http.addHeader("Content-Type", "application/json");

  StaticJsonDocument<512> doc;
  doc["device_id"]  = DEVICE_ID;
  doc["name"]       = WORKER_NAME;
  doc["zone"]       = ZONE;
  doc["ch4"]        = readCH4();       // your sensor reading function
  doc["co"]         = readCO();
  doc["o2"]         = readO2();
  doc["temp"]       = readTemp();
  doc["heart_rate"] = readHR();
  doc["battery"]    = readBattery();
  doc["panic"]      = panicPressed ? 1 : 0;
  doc["fall"]       = fallDetected  ? 1 : 0;

  String body;
  serializeJson(doc, body);

  int code = http.POST(body);
  Serial.printf("[SafeMine] Sent! Response: %d\n", code);  // 200 = success
  http.end();
}

Call it in your loop():

void loop() {
  // ... your existing sensor reading code ...

  sendToSafeMine();   // << add this line
  delay(3000);         // send every 3 seconds
}
The backend accepts many field name variants so even if your firmware uses "mq4", "methane", "bpm" etc. it will still work correctly.
5
Upload to ESP32
Flash the updated code
  1. Connect ESP32 to PC via USB cable
  2. Tools → Board → select ESP32 Dev Module
  3. Tools → Port → select your COM port (e.g. COM5)
  4. Click the Upload ► button (or Ctrl+U)
  5. Wait for "Done uploading"
If upload fails — hold the BOOT button on the ESP32 when you click Upload, release when you see "Connecting..."

After upload — open Serial Monitor to check:

  1. Tools → Serial Monitor
  2. Set baud rate to 115200
  3. You should see:
[WiFi] Connecting......
[WiFi] Connected! IP: 192.168.1.87
 [SafeMine] Sent! Response: 200   << 200 means SUCCESS
  [SafeMine] Sent! Response: 200
  [SafeMine] Sent! Response: 200
If you see Response: -1 or 0 → wrong IP address. Re-check Step 1 and update CLOUD_SERVER_URL.
6
Start SafeMine on Your PC
The server must be running to receive data
  1. Go to: C:\Users\HP\OneDrive\Desktop\Production_Envi\
  2. Double-click START_MINEGUARD.bat
  3. Wait for the console to show the startup banner
  4. Open browser: http://localhost:3001
You must keep this console window open while the ESP32 is sending data.

Verify the endpoint works — open this in your browser:

http://localhost:3001/api/health

You should see: {"status":"ok","system":"SafeMine"}

7
See Your Helmet on the Dashboard
Live data from the physical hardware
  1. Open http://localhost:3001
  2. Look for DHANA-001 in the Workers list
  3. You will see live: gas readings, heart rate, battery, zone, risk score
  4. The SafeMine backend console will show:
[HTTP Telemetry] ✓ DHANA-001 → CH4:0.12 CO:8.5 O2:20.7 HR:78
If you see your helmet ID on the dashboard with live sensor values — integration is 100% complete!

Test without ESP32 — paste this in Command Prompt:

curl -X POST http://localhost:3001/api/telemetry -H "Content-Type: application/json" -d "{\"device_id\":\"DHANA-001\",\"name\":\"Test Worker\",\"zone\":\"Zone A\",\"ch4\":0.5,\"co\":20,\"o2\":20.5,\"temp\":28,\"heart_rate\":85,\"battery\":75,\"panic\":0,\"fall\":0}"

Troubleshooting
If something is not working
ProblemFix
Response: -1 in Serial MonitorWrong IP. Run ipconfig again, update CLOUD_SERVER_URL in firmware
WiFi won't connectWIFI_SSID or WIFI_PASS is wrong (case sensitive)
Helmet not showing on dashboardMake sure START_MINEGUARD.bat is running and open http://localhost:3001/api/health
Response: 400JSON format issue. Check ArduinoJson version is v6.x
Response: 500Check the SafeMine console window for error message
ESP32 can't reach PC at allAllow port 3001 in Windows Firewall (see below)

Allow Port 3001 in Windows Firewall:

  1. Press Windows Key, search Windows Defender Firewall
  2. Click Advanced Settings
  3. Click Inbound Rules → New Rule
  4. Select Port → TCP → enter 3001
  5. Select Allow the connection → Finish
